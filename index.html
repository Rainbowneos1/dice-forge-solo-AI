📦 Offline single-file build: the model and data are embedded — just open this file (no server needed).

How this AI came to be

  • Network: a policy net 260 -> 1024 x3 -> 94 (about 2.46M parameters). The compliant path never uses the value net (decisions = policy argmax plus four deterministic rule fixes).
  • Training: four generations — ① search bootstrapping plus behaviour cloning (from v9); ② weighted fine-tuning on human expert demonstrations (v11-v12); ③ soft-label distillation (v16); ④ this v17: every game is additionally trained flipped left-to-right (same data budget, twice the effective samples), then advantage-weighted regression (AWR) on the return signal.
  • Result (compliant benchmark): 158.41 points — 5 fresh seed groups, 7,500 games evaluated pairwise, all five groups positive; +7.29 points (t = +37.63) versus v16. For reference: human expert 165.9, heuristic 104.0, random 38.8.
  • Compliance: every decision is argmax(policy net(260-d observable state)) followed by four rule fixes that read only that state — no branch simulation and no access to the rest of the game's draw stream. Three independent proofs: the same game replayed twice gives identical decisions; replacing the entire future draw stream leaves every action unchanged; and the code contains no search or randomness source.
  • Inference: weights are int8-quantized (per-output-channel, max absolute error 6.3x10⁻³) and dequantized to float32 when the page loads, so inference runs at full precision; one forward pass takes about 11-26 ms.
  • Reproducibility: each game's deck and roll sequence are pre-generated offline and consumed in order, so every game here plays out bit-for-bit the same way as the offline evaluation.
